ABSTRACT DEPARTMENT OF CSE (AI&ML)  •  MAJOR PROJECT – STAGE 1  •  2026–2027 02 Many research tasks require more than a single language-model response: they may need current web information, exact calculations, and evidence from local documents. This project presents a multi-use autonomous research agent that coordinates these capabilities through a ReAct-style Thought–Action–Observation loop. A language model interprets the request and selects among three tools: web search, a sandboxed mathematical calculator, and a local file reader. The system supports a Streamlit interface and terminal CLI, includes mock mode for testing without an API key, and is designed with API-key protection, file-path sandboxing, and automated tests. KEYWORDS Autonomous AI Agent • ReAct • LLM Tool Use • Web Research • Safe Computation • Local File Analysis • Streamlit RESEARCH Gather information from web sources. COMPUTE Evaluate supported expressions safely. SYNTHESIZE Combine observations into an answer.

PROBLEM STATEMENT DEPARTMENT OF CSE (AI&ML)  •  MAJOR PROJECT – STAGE 1  •  2026–2027 03 •  Static LLM knowledge may be outdated and cannot independently inspect local project files. •  Multi-part questions often require separate steps: find facts, extract values, calculate, and explain. •  Manual switching between browser, calculator, and files increases effort and can break the workflow. •  Unrestricted tool execution creates security risks, including unsafe expressions and file-path traversal. •  Users need visible execution steps and graceful error handling instead of silent failures. CORE PROBLEM How can an AI research assistant safely coordinate multiple tools to complete compound research tasks?

Adaptation The next step can respond to previous results or errors. The executor can continue until it produces a final answer. PROPOSED METHODOLOGY DEPARTMENT OF CSE (AI&ML)  •  MAJOR PROJECT – STAGE 1  •  2026–2027 09 01  QUERY INTAKE Receive the user’s compound research request. 02  REASON & PLAN LLM identifies missing information and a suitable next action. 03  TOOL SELECTION Choose web search, calculator or file reader. 04  EXECUTE & OBSERVE Run the tool and return a structured observation. 05  CONTINUE OR FINISH Use observations to choose another step or synthesize the answer. 06  PRESENT RESULT Display a final response through Streamlit or CLI.
